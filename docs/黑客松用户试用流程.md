# PetHome · 用户试用（约 3—5 分钟）

**让远方的爱宠，在手机里陪伴你。**

请使用组织者提供的网址，在同一浏览器中完成以下任务，不需要安装 App。

1. 进入“创建你的宠物”或“分身”，填写名字，上传一张清晰、只有一只猫或狗的照片。
2. 等待 AI 识别外观，看看匹配结果。不够像时，可手动选择最接近的预设，调整页面实际提供的颜色，再保存。
3. 进入小屋，试试摸头、点鼻、顺背、逗尾。也可以直接触摸角色，并用视角按钮查看它。
4. 试试“休息”和“唤醒”，打开夜灯，再刷新页面。确认宠物名字、外观以及小屋偏好仍然存在。

如果识别服务繁忙，界面会说明失败或降级。可以选择手动预设继续体验；这不算 AI 识别成功。

## 体验后请告诉我们

- 有没有一步不知道怎么继续，或哪个按钮没有达到预期？
- 数字分身哪些地方像你的宠物，哪些地方差异最大？
- 哪个互动让你有陪伴感？最希望优先改进什么？

这是“AI 外观识别 + 现有 3D 预设匹配”，不是照片直接生成高精度 3D 模型。猫咪支持原生动画；当前狗狗主要支持静态外观与整体轻反馈。数字分身的休息状态不代表现实宠物的状态。

资料保存在当前浏览器，并尝试同步到演示服务端。请使用同一访问地址继续体验。
