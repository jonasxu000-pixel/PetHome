# PetHome · 宠物数字小屋

手机优先的宠物数字世界：暖色房间、可分别活动的猫/狗分身、照片外观定制、四部位触摸、短视频行为同步与生活记录。升级范围见 [V2_IMPLEMENTATION.md](V2_IMPLEMENTATION.md)，原始 01—08 材料保留在上级目录。

## 启动

需要 Node.js 24。首次运行：

```powershell
npm ci
Copy-Item .env.example .env.local # 已有配置时不要覆盖
npm run dev -- --port 3001
```

开发地址 http://127.0.0.1:3001 ，开发缓存 .next-dev 与生产 .next 分离。生产运行：

```powershell
npm run build
npm start
```

生产地址 http://127.0.0.1:3000 。手机需与电脑处于同一局域网，通过电脑的 WLAN IPv4 和 3000 端口访问；实际可达性取决于网络与防火墙。公网发布需要另行确定部署目标和 HTTPS。

Windows 本地预览使用手动任务 PetHome-LocalPreview 独立运行，无自动开机触发。构建前先停止该预览任务及其对应的本项目 Node 进程，确认 3000 端口已释放；构建成功后再启动。不要批量停止其他项目的 Node 进程。

## 使用

1. 进入小屋，未建档时显示明确标注的通用小猫。昼夜切换会记住偏好。
2. 创建分身：填写名字、类型、性格，选择自己的宠物照片。图片原件不超过 8MB，压缩后保存在当前设备；读取外观时图像会发送至所配置视觉模型服务。
3. 预览分身，可修改毛色、花纹、耳型、眼睛与项圈。确认后保存；既有档案可编辑，保留原宠物 ID 与行为记录。
4. 在小屋里轻触头、鼻、后背或尾巴，也可用快捷按钮/数字键 1—4。部位分别运动，互动只改变虚拟反馈。
5. 在视频面板选择不超过 30 秒、32MB 的视频。优先 H.264 MP4，每 4 秒截一帧。原视频留在设备，抽取画面经服务端发送给模型。识别结果驱动分身，睡觉状态下互动会减弱。
6. 生活记录标明上传来源、未知和中断，不记录虚拟摸头为现实行为。

## 外观来源

- **通用分身**：尚未定制的模板。
- **照片配色定制**：在设备内提取照片中心区域的配色建议，耳型/花纹等由用户确认；没有冒充模型理解照片。
- **AI 照片定制**：服务端实际调用视觉模型读取猫/狗外观，返回模型标识及来源签名。保存时校验签名。
- **手动定制**：用户修改了外观；自动移除旧的 AI 来源凭证。

角色本体是有渐变体积感的 SVG 分层插画。当前支持猫/狗模板与上述外观参数，尚不重建任意宠物的全部体型或三维几何。性格目前保存为档案，没有独立性格模型。

## 低成本模型路线

默认调用智谱 **GLM-4.6V-Flash**；繁忙、超时或返回无效结果时，尝试同属免费路线的 **GLM-4.1V-Thinking-Flash**。官方模型页：[4.6V](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)、[4.1V](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.1v-thinking-flash)。免费服务仍受账户权限、并发与容量约束，不保证随时可用；不需要在本机部署模型。

在 .env.local 填入自己的智谱 Key：

```dotenv
AI_PROVIDER=zhipu
ZHIPU_API_KEY=在本机填写自己的密钥
GEMINI_API_KEY=
```

Key 只放服务端，不加 NEXT_PUBLIC_ 前缀，不提交 Git。默认智谱路径不会自动调用 Gemini。只有明确设置 AI_PROVIDER=gemini 才会启用该供应商。动画和触摸都在本地完成，不消耗模型调用。视频按至少 4 秒间隔发起连续帧请求，遇到繁忙时等待后最多重试一次；每次服务端请求最多尝试两个模型。服务进程限制每分钟最多 30 次上游视觉请求；这是本机进程保护，不是供应商计费上限或多实例配额。

未配置时，视频识别明确报错；照片定制保留配色建议供手动确认。2026-11-07 已使用用户 Key 与猫照、视频实测成功，具体范围见下文；这次成功不代表长期稳定性或识别准确率验收。

## 数据保存

- IndexedDB：当前浏览器的档案、照片、识别帧和时段记录。
- 服务端 .pethome-data/：匿名浏览器档案及分身外观，位于 public 之外并被 Git 忽略。通过 HttpOnly、SameSite Cookie 关联；本地档案为空时可从服务端恢复。
- 当前不是账号体系，不跨设备同步。清除全部站点数据（包括 Cookie）会失去匿名档案关联。行为记录仍仅存当前浏览器。
- 服务端文件存储依赖部署机器的持久磁盘；迁往无持久磁盘的平台时需要调整存储，不可把临时文件当云数据库。
